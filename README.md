# deliverable_1

INF201 (NMBU, H26) - Deliverable 1: analyse av værdata fra Ås (stasjon SN17850) med Frost-API-et til Meteorologisk institutt.

## Kjøre notebooken

Lag en bruker på https://frost.met.no og hent klient-ID.

Lagre ID-en i `frost_client_id.txt` i samme mappe som notebooken. Filen er ignorert av git og skal aldri committes.

Installer avhengigheter: `pip install pandas matplotlib requests pyyaml`

Åpne `deliverable_1.ipynb`.
